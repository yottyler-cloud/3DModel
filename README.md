# 3DModel
3Dモデリングのソフト

## Model3D.swiftpm(iPad / Swift Playgrounds)

2次元のスケッチ(図面)をもとに立体をつくる、履歴型の3Dモデラーの基本形です。

### 操作の流れ(一般的な3D CADの手順)
1. 左のフィーチャーツリーで「正面・平面・右側面」を選ぶか、3D表示で平らな面をタップする
2. 上のコマンドの「スケッチ」(またはスケッチタブの作図ツール)を押す → 平面に垂直な向きになり、2Dで描ける
3. 直線・コーナー矩形・中心矩形・円で閉じた図形を描く。スマート寸法で辺や円をタップして数値を入れる。スケッチフィレットで角を丸める
4. 「スケッチ終了」→ ツリーにスケッチができる
5. 「押し出し」または「押し出しカット」→ 左に設定パネル(PropertyManager)が出て、3Dでプレビュー。終了条件(ブラインド / 全貫通 / 中間平面)、反対方向、深さを決めて ✓
6. 「フィレット」→ 3D表示でエッジをタップして選び、半径を入れて ✓

平面を選ばずに「押し出し」を押すと、平面を選ぶよう案内が出ます。選ぶとスケッチになり、スケッチ終了でそのまま押し出しに進みます。

### できること
- フィーチャーツリー: 基準平面・原点・フィーチャー(押し出しの下にスケッチ)、フィーチャー編集、スケッチ編集、抑制、名前の変更、削除、ロールバックバー(「ここまでロールバック」)
- コマンド: 「フィーチャー」タブ(押し出し / 押し出しカット / フィレット / スケッチ)、「スケッチ」タブ(作図ツール)
- 右上の ✓ / ✗(確定・取消)、元に戻す / やり直し
- 表示: 全体表示、標準の向き(等角・正面・背面・左右・上・底・垂直表示)、エッジ表示の切りかえ
- スナップ: 格子・図形の点・原点・同じ平面のスケッチ・形の稜線の端点
- STL(バイナリ)書き出し、自動保存(書類フォルダの part.json)

### 開き方
`Model3D.swiftpm` フォルダを iPad の Swift Playgrounds(または Mac の Xcode)で開いて実行します。

### 中身
| フォルダ | 内容 |
| --- | --- |
| `Sources/Geometry` | ベクトル、2D多角形(三角形分割・オフセット)、BSPによるブーリアン演算、押し出し形状の生成 |
| `Sources/Model` | スケッチ・フィーチャーのデータ、履歴・元に戻す・ロールバック・保存、STL書き出し |
| `Sources/Editor` | 操作の流れ(スケッチ・押し出し・フィレットのコマンドと選択)、スケッチの作図 |
| `Sources/Views` | コマンドバー、フィーチャーツリー、PropertyManager、グラフィックス領域 |

### いまの制限
- フィレットで選べるのは、押し出し・カットのふち(スケッチ面側・先端側)と、図形の角から伸びる縦のエッジ。ふちを選ぶと、そのフィーチャーの同じ側のふちがすべて丸くなる
- 2つのフィーチャーがぶつかってできたエッジ(板とボスの付け根など)は選べない
- 内側へ丸めるRが形に対して大きすぎると、自動で小さくする
- 拘束(水平・一致など)や、寸法を図に残す機能はまだない
