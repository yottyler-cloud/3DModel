# 3DModel
3Dモデリングのソフト

## Model3D.swiftpm(iPad / Swift Playgrounds)

2次元のスケッチ(図面)をもとに立体をつくる、履歴型の3Dモデラーの基本形です。

### できること
- **スケッチ**: XY / XZ / YZ 平面(オフセット指定可)に、長方形・円・多角形を描く
  - 格子と点(角・中心・原点・ほかのスケッチ)へのスナップ
  - 数値での編集(位置・幅・高さ・直径・頂点座標)
  - 図形の中にある図形は「穴」として扱う
- **押し出し**: スケッチに厚みをつけて形を足す(法線方向 / 反対方向 / 両側対称)
- **引き抜き**: スケッチの形で削る(距離指定 / 貫通)
- **フィレット**
  - 角R: スケッチの角(=縦のエッジ)を丸める。角ごと、またはすべての角
  - エッジR: 押し出しのふち(スケッチ面側・先端側)、引き抜きの入口のふちと底のすみを丸める
- 履歴の編集・並べ替え・一時的に無効・削除(変更すると形を作り直す)
- 3D表示(指1本で回転、2本で移動、ピンチで拡大縮小)、視点切り替え
- STL(バイナリ)の書き出し・共有
- 自動保存(アプリの書類フォルダの model.json)

### 開き方
`Model3D.swiftpm` フォルダを iPad の Swift Playgrounds(または Mac の Xcode)で開いて実行します。

### 中身
| フォルダ | 内容 |
| --- | --- |
| `Sources/Geometry` | ベクトル、2D多角形(三角形分割・オフセット)、BSPによるブーリアン演算、押し出し形状の生成 |
| `Sources/Model` | スケッチ・特徴(押し出し/引き抜き)のデータ、状態管理と保存、STL書き出し |
| `Sources/Views` | 履歴と3D表示の画面、スケッチ編集画面 |

### いまの制限
- エッジのフィレットは、押し出し・引き抜きの端のふちだけ(任意のエッジを選んで丸めることはまだできない)
- 内側へ丸めるRが形に対して大きすぎると、自動で小さくする
- 面を選んでスケッチする機能はまだない(平面とオフセットで指定。「形の上端へ」ボタンあり)
